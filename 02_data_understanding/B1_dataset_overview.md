# Dataset Overview

## Overview

This project uses the **Olist Brazilian E-Commerce Public Dataset**, a real-world marketplace dataset published by Olist and made publicly available through Kaggle.

The dataset captures transactional data generated by a Brazilian e-commerce marketplace, covering the complete customer purchase lifecycle from order placement to post-purchase reviews. It includes information related to customers, orders, products, sellers, payments, deliveries, and customer feedback.

The dataset represents marketplace activity between **September 2016 and October 2018**, providing a comprehensive view of marketplace operations over approximately two years.


## Business Domain

The dataset represents a multi-vendor e-commerce marketplace where:

- Customers purchase products from independent sellers.
- Sellers list products and fulfil customer orders.
- Payments are processed using multiple payment methods.
- Orders progress through different fulfilment stages.
- Customers provide reviews after receiving their orders.

This structure enables analysis across multiple business functions, including revenue, customer behaviour, seller performance, product performance, payment behaviour, and operational efficiency.


## Dataset Scope

The analysis focuses on the following business entities:

- Customers
- Orders
- Order Items
- Products
- Sellers
- Payments
- Reviews
- Geolocation
- Product Category Translation

Together, these entities represent the core operational data required to analyse marketplace performance and customer experience.


## Dataset Structure

The dataset consists of **9 relational tables** connected through primary and foreign key relationships.

| Table | Description |
|--------|-------------|
| customers | Customer information and location details |
| orders | Order lifecycle and delivery information |
| order_items | Individual products purchased within each order |
| products | Product attributes and physical characteristics |
| sellers | Marketplace seller information |
| payments | Payment details for each order |
| reviews | Customer ratings and review information |
| geolocation | Geographic reference data based on ZIP code prefixes |
| category_translation | Portuguese product categories translated into English |


## Data Characteristics

The dataset contains:

- Approximately **100,000 customer orders**
- Over **112,000 order items**
- More than **32,000 products**
- More than **3,000 sellers**
- Nearly **100,000 customer reviews**
- Over **1 million geolocation records**

The data includes both transactional and descriptive information, enabling analysis at multiple levels of granularity.
